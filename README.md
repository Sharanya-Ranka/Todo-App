# Todo-App
This is a slightly gamified, but yet simple Todo app. Earn coins by completing tasks, which you can then spend on rewards. Both tasks and rewards are to be defined by the user.

This project was largely vibe-coded thanks to Google-Gemini (Flash version) 

You can try the app here: [Todo App](https://main.d1xqvpqisk7a2h.amplifyapp.com/)

### Main Features
1) Earn + Spend system to gamify todos.
2) Deeply nested tasks allow you to express complex dependencies.
3) All data is stored on client-side (locally). There is no communication with the server except for the web-app contents itself.
